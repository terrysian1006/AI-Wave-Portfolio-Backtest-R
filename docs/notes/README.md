# notes：章節原始筆記

每一個章節頁都先有一份筆記，再依筆記寫成 HTML。筆記是頁面內容的唯一依據，AI 寫頁面時只能使用筆記裡的文字與數字。

## 命名

與章節頁同名，例如 `chapters/04-results.html` 對應 `notes/04-results.md`。

## 格式

```markdown
# 編號 章名

- 對應報告：第 N 章（第 x 至 y 頁）
- 一句話摘要：……

## 本章重點
- 重點一（含數字）
- 重點二
- 重點三

## 各節內容
### N.1 節標題
- 要點……

## 數字與出處
| 數字 | 意思 | 出處 |
|---|---|---|
| 1.249 | NS-GMVP 夏普指標 | 表 6 |

## 圖表
- 圖 N：圖名 → assets/img/fig-0N.jpg
- 表 N：表名 → 放在 report-data.js 或直接寫在頁面

## 待確認
- 報告前後不一致或缺資料的地方
```
