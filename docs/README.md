# Human Premium vs. the AI Shock: Website

Web version of my Financial Data Analysis final report, *Human Premium vs. the AI Shock: Building a Defensive Portfolio Through the Generative-AI Boom*.

- 37 US-listed stocks and ETFs, grouped into five categories by how AI affects them
- 7 portfolio strategies (1/N, B&H, GMVP, NS-GMVP, MVP, NS-MVP, Tangency)
- Out-of-sample rolling-window backtest over 522 trading days, net of transaction costs
- Key finding: the no-short-sale global minimum variance portfolio (NS-GMVP) was the most stable, with a Sharpe ratio of 1.249 and a maximum drawdown of 6.5%

# 人性溢價與反 AI 烏托邦：網頁版

財務金融資訊分析期末報告〈人性溢價與反 AI 烏托邦：AI 狂潮下的逆勢投資組合建構與績效比較〉的網頁版。

- 37 檔全球股票與 ETF，依受 AI 衝擊的方式分成五組
- 7 種投資組合策略（1/N、B&H、GMVP、NS-GMVP、MVP、NS-MVP、Tangency）
- 522 個交易日的樣本外滾動回測，計入交易成本
- 主要發現：禁止放空的最小變異數組合（NS-GMVP）夏普指標 1.249、最大回撤 6.5%，表現最穩
